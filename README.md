# ascii-synth

A terminal piano you play with your computer keyboard. Available for macOS and
Linux.

## Install and run

Install with [pipx](https://pipx.pypa.io/):

```sh
pipx install --python python3.13 ascii-synth
asynth
```

Python 3.13 must be installed. Supported Python versions are 3.11 through 3.13.

Run `asynth` in a terminal with audio output available. Press these keys to
play notes:

```text
	┌───────┬───────┐       ┌───────┬───────┬───────┐
	│   W   │   E   │       │   T   │   Y   │   U   │
┌───┴───┬───┴───┬───┴───┬───┴───┬───┴───┬───┴───┬───┴───┬───────┐
│   A   │   S   │   D   │   F   │   G   │   H   │   J   │   K   │
└───────┴───────┴───────┴───────┴───────┴───────┴───────┴───────┘
```

Press `Esc` or `Ctrl+C` to quit.
